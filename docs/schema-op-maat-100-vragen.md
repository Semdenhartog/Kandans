# Schema op maat – 100 vragen van de loper (11-11-2026)

Doel: de coach maakt uitgebreide hardloopschema's naar de wensen van de loper. Hieronder de 100 vragen die een loper zich
stelt bij een schema, en wat de app daarop antwoordt. **✔** = in deze ronde gebouwd, **·** = later / bewust niet.

## 1. Doel en richting
1. ✔ Kan ik een schema maken voor 5 km, 10 km, 15 km, halve of hele marathon? → acht doelen in "Schema op maat".
2. ✔ Kan ik een schema krijgen zonder wedstrijd, gewoon om fitter te worden? → doel "Fit blijven" (vaste duur).
3. ✔ Kan ik sneller worden zonder dat ik een wedstrijd heb? → doel "Sneller worden".
4. ✔ Ik begin net: kan ik een schema van 0 naar 5 km krijgen? → doel "Beginnen" (loop-wandelblokken).
5. ✔ Ik kom terug na een blessure of pauze, kan dat rustig? → doel "Terugkomen" (extra voorzichtig).
6. ✔ Kan ik een doeltijd opgeven? → optioneel, met haalbaarheidscheck.
7. ✔ Zegt de app eerlijk als mijn doeltijd niet realistisch is? → melding "ambitieus" of "erg ambitieus" + voorspelde tijd.
8. ✔ Kan ik een wedstrijd uit Mijn wedstrijden kiezen? → datum en afstand worden overgenomen.
9. ✔ Hoeveel weken heb ik nodig? → advies per doel; bij te kort een waarschuwing.
10. ✔ Kan ik kiezen hoe lang het schema duurt als er geen wedstrijd is? → 6–24 weken.

## 2. Mijn niveau
11. ✔ Weet de app hoeveel ik nu loop? → weekgemiddelde van de laatste 4 weken, aan te passen.
12. ✔ Wat als ik nog geen runs in de app heb? → zelf invullen (km per week, langste run).
13. ✔ Rekent de app mijn tempo's uit? → uit je runs (drempeltempo) of uit een recente 5 km-tijd.
14. ✔ Kan ik een recente wedstrijdtijd invullen voor betere tempo's? → 5 km-tijd optioneel.
15. ✔ Houdt het schema rekening met mijn langste recente run? → lange duurloop start daar vlakbij.
16. ✔ Houdt het rekening met mijn leeftijd? → 50+: meer herstel, rustweek elke 3 weken.
17. ✔ Kan ik aangeven dat ik snel geblesseerd raak? → kleinere stappen, max 1 zware training, extra rust.
18. · Leest de app mijn VO2max van mijn horloge? → nee, te onbetrouwbaar; tempo's uit runs.
19. ✔ Wat als ik helemaal niet weet hoe snel ik loop? → standaard praattempo-uitleg + gevoel (RPE).
20. ✔ Kan ik aangeven hoe ambitieus ik ben? → rustig / gebalanceerd / ambitieus.

## 3. Tijd en planning
21. ✔ Kan ik kiezen op welke dagen ik loop? → dagkiezer ma–zo.
22. ✔ Kan ik de dag van de lange duurloop kiezen? → ja.
23. ✔ Kan ik zeggen hoeveel tijd ik doordeweeks heb? → max 30/45/60/75/90 min, trainingen passen daarbinnen.
24. ✔ Kan ik 2 tot 6 keer per week lopen? → ja, schema schaalt mee.
25. ✔ Kan ik een vrije week inplannen (vakantie)? → "Week zonder lopen" (week overslaan, daarna rustig weer op).
26. ✔ Schuift het schema mee als ik een training mis? → ja (bestaande planner), nooit inhalen.
27. ✔ Staat mijn training van vandaag op Vandaag? → ja, looptrainingen gaan in je plan.
28. · Houdt het rekening met mijn werkrooster? → via het bestaande rooster bij het beste moment, niet in de opbouw.
29. ✔ Kan ik kiezen in kilometers of in minuten? → weergave per keuze.
30. ✔ Kan ik zien hoeveel tijd ik per week kwijt ben? → uren per week in het overzicht.

## 4. Inhoud van de trainingen
31. ✔ Krijg ik afwisseling (rustig, lang, tempo, intervallen)? → ja, per fase anders.
32. ✔ Staat erbij hoe snel elke training moet? → tempo per training + tempo-tabel.
33. ✔ Staat erbij hoe zwaar het moet voelen? → zwaarte 1–10 (RPE) per training.
34. ✔ Staat bij elke training een warming-up en cooling-down? → in drie delen: inlopen, kern, uitlopen.
35. ✔ Krijg ik heuveltraining als mijn wedstrijd heuvels heeft? → terrein "Heuvelachtig" of "Trail".
36. ✔ Krijg ik versnellingen (strides)? → bij rustige runs in opbouw- en piekfase.
37. ✔ Worden intervallen begeleid door de stem? → ja (bestaande intervalcoach).
38. ✔ Kan ik een training direct starten vanuit het schema? → ja (bestaande startknop).
39. ✔ Krijg ik een uitleg waarom een training erin staat? → "Waarom" per training en per week.
40. ✔ Wordt de lange duurloop rustig opgebouwd? → max ±10% per week, met rustweken.

## 5. Naast het lopen
41. ✔ Kan ik krachttraining in mijn schema krijgen? → 0, 1 of 2 keer per week, op loopvrije dagen.
42. ✔ Welke krachtoefeningen precies? → vaste routine met sets en herhalingen, per fase.
43. ✔ Kan ik fietsen of zwemmen erbij doen? → crosstraining op een vrije dag, als je dat wilt.
44. ✔ Krijg ik mobiliteit of rekken? → korte mobiliteitsroutine na de lange duurloop.
45. ✔ Staan rustdagen ook in het schema? → ja, met wat je wel mag (wandelen).
46. ✔ Kan ik op de loopband trainen? → loopband-tips bij tempo en intervallen als je dat aangeeft.
47. ✔ Krijg ik voedingstips voor lange runs? → vanaf 75 minuten: drinken en koolhydraten.
48. ✔ Krijg ik tips voor slaap en herstel? → in de wekelijkse focus.
49. · Krijg ik een voedingsschema? → nee, geen diëtist; alleen algemene tips.
50. ✔ Staat erbij wanneer ik nieuwe schoenen moet testen? → tip in de week voor de laatste lange run.

## 6. Overzicht en vormgeving
51. ✔ Zie ik in één keer het hele schema? → overzicht per week, inklapbaar.
52. ✔ Zie ik in welke fase ik zit? → fasebalk: basis, opbouw, piek, afbouw.
53. ✔ Zie ik het aantal kilometers per week? → staafjes per week + getal.
54. ✔ Zie ik mijn tempozones op één plek? → tempo-tabel met 5 zones.
55. ✔ Is het rustig en overzichtelijk? → donker-goud, kleuren per type, geen drukte.
56. ✔ Zie ik de belangrijkste trainingen? → "sleuteltrainingen" gemarkeerd.
57. ✔ Kan ik zien wat deze week de focus is? → één zin focus per week.
58. ✔ Is het in het Nederlands, zonder jargon? → ja, met korte uitleg bij termen.
59. ✔ Werkt het in licht en donker? → het schema is altijd donker-goud (luxe), de PDF op papierwit.
60. ✔ Kan ik het lezen met grote letters? → lettergrootte van de telefoon wordt gevolgd.

## 7. Downloaden en delen
61. ✔ Kan ik het hele schema downloaden? → PDF, in één tik.
62. ✔ Kan ik het printen en op de koelkast hangen? → PDF op A4, met weekoverzicht.
63. ✔ Staat alles in de PDF (tempo's, uitleg, kracht)? → ja: voorblad, tempo's, fases, alle weken, wedstrijddag.
64. ✔ Kan ik het delen met mijn trainer of maatje? → delen via WhatsApp, mail enz.
65. ✔ Is de PDF mooi genoeg om te bewaren? → strak, papierwit met goud en espresso, Saira en DM Sans.
66. · Kan ik het in mijn agenda zetten? → later (ICS-export).
67. · Kan ik het naar mijn horloge sturen? → losse intervaltrainingen kan al; hele schema later.
68. ✔ Kan ik de PDF opnieuw maken na een wijziging? → ja, de PDF komt altijd uit het huidige schema.
69. ✔ Staat mijn naam en doel erop? → ja, op het voorblad.
70. ✔ Is de PDF ook bruikbaar zonder app? → ja, alles staat erin.

## 8. Aanpassen
71. ✔ Kan ik het schema later aanpassen? → wensen staan klaar, opnieuw maken in één tik.
72. ✔ Kan ik een andere dag kiezen voor een training? → in het bestaande schema (verplaatsen).
73. ✔ Past het schema zich aan bij slecht weer? → bestaand weerslim wisselen.
74. ✔ Wat als ik ziek word? → advies in de coach + week overslaan.
75. ✔ Kan ik van ambitie wisselen halverwege? → opnieuw maken vanaf vandaag.
76. ✔ Blijven mijn gedane trainingen staan? → gedane runs staan in Logboek, los van het schema.
77. ✔ Kan ik het schema verwijderen? → ja (bestaand).
78. ✔ Kan ik eerst een voorbeeld zien voor ik het opsla? → ja, overzicht vóór opslaan.
79. ✔ Waarschuwt de app als ik te veel wil? → bij te weinig weken of te grote sprong in omvang.
80. ✔ Kan ik de coach vragen een schema te maken? → "Maak een schema" in de coach opent Schema op maat.

## 9. Wedstrijd
81. ✔ Krijg ik een afbouw (taper)? → afhankelijk van de afstand 1–3 weken.
82. ✔ Krijg ik een wedstrijdplan? → indeling, eten en drinken, inlopen.
83. ✔ Krijg ik een tempo per kilometer voor de wedstrijd? → doeltempo + start iets rustiger.
84. ✔ Wat eet ik de dag ervoor en die ochtend? → in het wedstrijdplan.
85. ✔ Wat neem ik mee? → paklijst in het wedstrijdplan.
86. ✔ Hoe lang herstel ik daarna? → herstelweek na de wedstrijd in het plan.
87. ✔ Krijg ik een voorspelde eindtijd? → op basis van je drempeltempo.
88. ✔ Wordt rekening gehouden met een tweede wedstrijd tussendoor? → als "testloop" in de piekfase (optioneel).
89. · Past het tempo zich aan het weer van de wedstrijddag aan? → bestaand (hitte-aanpassing bij start).
90. ✔ Staat de wedstrijd in Mijn wedstrijden? → ja, als je hem daar koos.

## 10. Vertrouwen en veiligheid
91. ✔ Is het schema veilig voor beginners? → loop-wandelen, max ±10% opbouw.
92. ✔ Wat als ik pijn krijg? → vaste tekst: stoppen, rust, fysio; geen diagnose.
93. ✔ Is het gebaseerd op echte trainingsprincipes? → polarisatie (±80% rustig), periodisering, rustweken.
94. ✔ Kost dit AI-geld? → nee, het schema wordt op de telefoon berekend.
95. ✔ Werkt het zonder internet? → maken en PDF wel; opslaan in je plan vraagt internet.
96. ✔ Worden mijn gegevens gedeeld? → nee, alleen je looptrainingen gaan naar je eigen plan.
97. ✔ Is het voor 50-plussers aangepast? → ja (zie 16).
98. ✔ Voor zwangeren of mensen met een aandoening? → advies: eerst arts; geen speciaal schema.
99. ✔ Kan ik het schema vertrouwen als ik weinig data heb? → app zegt eerlijk dat tempo's een schatting zijn.
100. ✔ Waar vind ik het? → Ik → Trainingsschema → "Schema op maat", en via de coach.
